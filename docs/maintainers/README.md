# Maintainer Docs

These documents are for repository maintainers and release work. They are intentionally kept out of the main newcomer path.

- `publishing.md`
  Publication gates and release sequencing for GitHub and pack-db.
- `package-readiness.md`
  Package-by-package readiness notes for release waves.
- `pack-db-wave1.md`
  First-wave pack-db handoff material and draft package entries.

Supporting release verification material:

- `tutorials/wave1-kernel/README.md`
  Narrow downstream proof for the first proposed public package wave.
- `scripts/verify-wave1.sh`
  Narrow verification command for the proposed Wave 1 package set.
- `scripts/verify-release.sh`
  Whole-repo verification command used before public release work.
